The Sand Table, Small Versions

The desk test already holds the core of the object: a brass plate, a driver, an amplifier and beads, plus a computer that turns a number into a settled or smeared figure. Everything else in the full build exists to make it beautiful, permanent and hard to tamper with. These versions keep the core and say plainly what they give up.

Tier 1kitchen table, about $120–220
Tier 2honest version, about $300–500
One afternoonfor Tier 1, in a workshop
Plusa computer you already own

What every version keeps

  • The figure: crisp means settled, smeared means unsettled. The sound and the figure are the same vibration.
  • Measured, not reported: the number comes from the model's own word probabilities, never from the agent describing itself.
  • The worst moment counts: one torn step in a task can't hide inside a confident answer.
  • Settled isn't right: the figure shows how the model behaved, not whether its work was correct. The log has a column to mark that.

Start with the desk test

Both versions begin with the desk test (the-sand-table-desk-test.pdf): the same plate, amplifier and beads. It answers the question these versions depend on most: does your driver make clean figures, and does added noise visibly smear them? If you're choosing between the two cheap drivers below, test both.

Tier 1 · The kitchen table

One computer runs the model, the meter and the agent. There's no controller: the meter plays each verdict to the plate itself, with the same sound the controller makes. Setup steps: software/KITCHEN-TABLE-SETUP.txt.

  1. Set up the plate as in the desk test, in its tray. Run the USB sound adapter into the amplifier, with the amplifier turned all the way down.
  2. Install a model you run yourself with llama.cpp. A small one that supports tool calls is enough. Most hosted AI services don't share word probabilities, so the table can't read them.
  3. Choose your figure with python3 plate.py sweep, or save the note your desk test found. Set the amplifier so a test verdict forms the figure in about 3 seconds.
  4. Start the meter in audio mode and point the agent at it, never at the model directly.
  5. Give the agent a task. When it finishes, the plate plays the verdict.
What Tier 1 gives up: isolation. The agent, the model and the meter share one computer, so "the agent can't reach the meter" is a software promise, not a physical one. Anything on that computer could read the meter's numbers, call the model directly, or play sounds of its own. There are no counters, and the loudness ceiling is a setting on the computer plus the amplifier's knob. That's fine for a demo, as long as the placard says so.

Tier 2 · The honest version

Everything in Tier 1, plus the parts that make the honesty claim physical: the agent lives on a Raspberry Pi whose only way to the meter is one cable, and the plate is played by a controller that listens down a one-way wire and can't talk back. Setup steps: software/HONEST-VERSION-SETUP.txt.

  1. Give the meter its own account on your computer (macOS or Linux), owning the model and the meter. Your computer keeps its Wi-Fi and its everyday use.
  2. Run one cable from your computer to the Pi, and switch on the firewall that locks down only that cable: the agent can reach the meter's one port, and nothing else, in either direction.
  3. Set up the Pi with its Wi-Fi and Bluetooth off and the agent in an account without admin rights. It has no internet.
  4. Build the controller with the full build's firmware: the Pico, the sound board, two counters and the one-way wire. The light and telltale pins stay unconnected.
  5. Check the separation from the Pi: the meter answers; the model, SSH and the internet don't.
What Tier 2 gives up. The meter shares a computer with your everyday life, so that computer's security is only as good as its settings. There's no key: the agent never goes online or acts in the world. No lights and no case. The isolation itself is real: the agent's only path is one cable, and the table can't talk back.

Running it as a workshop

  • Do the desk test once beforehand, with the exact plate and driver everyone will use, and write down the notes that make clean figures. Then nobody has to sweep: each table saves a known note with plate.py save.
  • Prepare the software in advance: llama.cpp, a small model, and the software folder on each laptop. Downloads are the slowest part of the afternoon.
  • A rough afternoon: 30 minutes for the plate and tray, 30 for the software, 15 to save the note and set the loudness, then the rest giving the agent easy and impossible tasks and watching the difference.
  • Safety: glass microbeads only, never silica sand. Keep the bags closed and away from small children. Ear protection while setting the loudness. Start every amplifier turned all the way down.
