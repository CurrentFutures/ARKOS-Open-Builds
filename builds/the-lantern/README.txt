The Lantern: a media player and lamp for beside the TV.

the-lantern-model.html          The interactive 3D model, and the tool that makes the build files.
                                Choose the glass and film colors, then press:
                                  "Cut files"   -> lantern-cut-files.zip (DXF for the acrylic and aluminum shops + order sheet)
                                  "Print files" -> lantern-print-files.zip (17 pane prints, true size, + print notes)
the-lantern-build-guide.pdf/.html  Step by step: parts and sourcing links, drawings, glass, metal,
                                concrete, electronics, software, assembly and tests.

Everything works offline. Each HTML file is a single self-contained page.
superseded/ holds the earlier one-page build sheet; the guide replaces it.
